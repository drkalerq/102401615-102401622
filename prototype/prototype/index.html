校园失物招领 · 交互原型

这是一个数据驱动的手机原型，覆盖作业全部页面与三条演示流程：

① 首页 → 点卡片 → 详情（查看信息 → 查看详情）
② 底部「+」→ 发布页 → 选类型 → 填写 → 发布（发布信息 → 发布成功，新信息会进入首页与"我的"）
③ 搜索页 → 输入关键词 → 实时结果（搜索物品 → 查看结果）

托管为在线链接：把本文件夹推送到 GitHub 并开启 Pages，即可得到可分享、可点击的原型链接。

提示：所有页面、跳转、搜索、发布均为真实交互；占位数据可在源码 items 数组中修改。
