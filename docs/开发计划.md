# 开发计划与验收标准

## 范围

沿用第一次原型的五个页面、蓝白配色和字段设计。采用 HTML、CSS、JavaScript 与浏览器本地存储，实现可下载、可直接打开的 Web 网页。

## 阶段提交

| 阶段 | 内容 | 验收标准 |
| --- | --- | --- |
| 1 | 原型归档、范围、分工、PSP 预估 | 文档链接有效，原型能够打开 |
| 2 | 页面框架、首页、导航和类型筛选 | 页面切换正常，寻物与招领筛选正确 |
| 3 | 发布与本地保存 | 必填项校验，新内容进入首页，刷新不丢失 |
| 4 | 搜索与详情 | 关键词和类别组合有效，空结果提示清楚，返回保留筛选 |
| 5 | 联系方式复制 | 成功才显示已复制，失败时允许手动复制 |
| 6 | 我的发布与状态更新 | 寻物标记已找回，招领标记已归还，各页面同步 |
| 7 | 编辑与删除 | 编辑保存一致，删除需要确认，取消不改变数据 |
| 8 | 图片上传与线索推荐 | 图片可预览保存；推荐仅提供未完成的相反类型线索 |
| 9 | 测试和文档 | 至少 10 个有效单元测试，运行说明、流程图、截图完整 |
| 10 | 搭档完善与修复 | 通过分支与 PR 记录实际改动，修复后回归检查 |

各阶段可按独立功能继续拆分 commit，不补造历史提交。

## 评分材料

- 博客：组员链接、仓库链接、分工、PSP、实现思路、流程／数据流图、关键代码说明。
- 附加功能：设计意义、实现过程、关键代码和实际效果。
- 测试：工具使用说明、用例设计、测试结果；覆盖正常输入、边界和异常情况。
- 过程：真实 commit 截图，实际问题和尝试过程、搭档评价。
- 程序：功能完整、界面清楚、中文无乱码、下载运行方便、README 与实际行为一致。
