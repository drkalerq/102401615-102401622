## 计划实现

- 首页浏览寻物与招领信息，按类型筛选。
- 发布信息：名称、类别、地点、时间、描述、联系方式。
- 关键词与类别搜索，查看详情和复制联系方式。
- 我的发布：编辑、删除、标记已找回或已归还。
- 刷新后保留数据；图片上传与预览。
- 附加功能：相似寻物／招领线索推荐（规则匹配，不保证属于同一物品）。

## 查看现有参考原型

下载仓库 ZIP 并解压，用 Chrome 打开 `prototype/prototype/index.html`。
这是第一次作业的参考原型，不能作为第二次程序的完成版本。

## 运行正式网页与测试

下载仓库 ZIP 并解压，使用 Chrome 打开根目录 `index.html`，无需安装依赖或启动服务器。不要只下载 HTML，需要同时保留 css、js 文件夹。

单元测试需要 Node.js 22 或更新版本，无需安装 npm 依赖。在项目根目录执行：

```bash
node --test tests/core.test.js
```

本阶段应通过 6 个测试；后续随功能实现扩展。

## 数据范围

计划使用浏览器 localStorage。本地数据仅保存在当前浏览器中，不支持不同设备实时共享；不包含后台、登录、实名认证或即时聊天。
