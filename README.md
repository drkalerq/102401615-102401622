## 发布与保存

进入“发布”选择寻物／招领，填写物品名称、类别、地点和联系方式。时间可选，不填则使用发布时刻；详细描述可选。保存成功后返回首页并显示成功提示。

始终在同一个目录，用同一个 Chrome 用户配置打开 index.html 验证刷新保存。移动文件、切换浏览器或清除站点数据后，原内容可能无法访问。file:// 下本地存储行为依赖浏览器，应由测试人员实际验证。

如果保存失败，表单和当前列表保持原状，修复存储设置后可重试。如果读取到损坏或不兼容的记录，程序暂停发布，避免自动覆盖原数据；处理前先备份原始存储内容。

## 搜索与详情

点首页搜索入口或底部搜索导航。关键词会匹配名称、地点、类别和描述；多个词用空格分隔时，结果须同时包含所有词；英文忽略大小写。类型、类别和“仅看未完成”可以组合使用。点击清空筛选可恢复全部结果。

点击首页或搜索结果卡片查看完整信息；点击“联系发布者”展开联系方式。点击“复制联系方式”使用浏览器剪贴板 API；失败时会提示并选中联系方式，可按 Ctrl+C 手动复制。点击详情页“返回列表”保留此前的类型或搜索条件。浏览器刷新当前版本会回到首页，未保存的搜索条件不持久化。

## 我的发布与状态

进入“我的”查看当前浏览器中标记为自己发布的内容。初始演示数据中有两条属于“我”的已完成信息。可以筛选全部、进行中和已完成。寻物标记为已找回，招领标记为已归还；确认后保存，首页、搜索和详情会显示更新后的状态。已完成信息可以恢复为进行中。

此版本使用本地 isMine 字段区分自己的信息，不是账号登录或服务器权限机制。不同设备不共享归属。状态保存失败时保持原状态并显示错误，不报告更新成功。

一键复制取决于浏览器权限。出现复制成功提示后，可粘贴到记事本验证；失败时按提示手动复制。

## 编辑与删除

在“我的发布”点击编辑，共用发布表单，修改后点击保存修改。发布编号、发布时间、归属、图片和完成状态保留；改变寻物／招领类型时，完成状态文案随类型变化。时间留空保留原时间。此前未提交的新发布草稿会在退出编辑后恢复。取消编辑或切换页面需要确认放弃编辑，原信息不变。

删除需要确认且不能恢复；取消确认不改变数据。修改和删除都先保存，再更新列表；保存失败保留原记录，编辑表单可继续重试。

## 照片上传与保存

发布和编辑表单可选择一张 JPG、PNG 或 WebP，原文件不超过 5 MB。照片缩至最长边 1280 像素以内，转成 JPEG，透明背景为白色；照片数据最多 500000 个字符，过大则提示换图。图片处理中提交暂不可用，处理完成后可发布或保存。照片是选填项。

预览表示照片已准备好，只有点击发布／保存修改并保存成功，记录才生效。首页、搜索、我的卡片显示照片缩略图，详情显示完整比例图片。没有照片时使用类别图标。编辑可更换或移除照片，取消编辑不会修改已保存照片，之前的新发布草稿及其照片会恢复。连续选图以最后一次为准。无效文件或解码失败会保留之前照片并显示提示。

图片数据随记录存入 localStorage，不依赖本地照片路径；刷新应仍显示。多张照片累计可能耗尽浏览器存储，失败时原列表不变、表单保留，可移除照片后重试。Node 自动测试覆盖规则和异步状态；真实照片的浏览器解码、压缩和显示需要按验收文档操作检查。

## 相似线索推荐

打开未完成物品的详情，在下方“相似线索”中查看最多三条相反类型、同类别、名称相似的未完成记录。事件时间均有效时，两条信息时间相差超过七天则排除；地点和时间更接近会提高排序。每条结果显示推荐理由，可以点击查看详情并联系发布者，返回列表保留原来的首页／搜索／我的来源。已完成信息停止推荐；没有结果时显示暂无线索。

规则只用于缩小核对范围，不保证是同一件物品。地点依据文字匹配，没有地图定位；照片与联系方式不参与匹配。详见 `docs/线索推荐设计.md`。
